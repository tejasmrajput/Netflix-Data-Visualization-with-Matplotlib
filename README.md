📌 Project Description

Netflix Content Analysis & Visualization using Python (Pandas & Matplotlib)

Developed a data analysis project using the Netflix Titles dataset to explore content trends and generate meaningful insights. The project includes data cleaning, preprocessing, and multiple visualizations to analyze the distribution of Movies and TV Shows, yearly content releases, content ratings, and movie duration patterns. The analysis was performed using Pandas for data manipulation and Matplotlib for data visualization.

🔹 Key Features
Imported and analyzed the Netflix dataset using Pandas.
Cleaned missing values to improve data quality before analysis.
Compared the number of Movies and TV Shows using a Bar Chart.
Visualized content distribution with a Pie Chart.
Analyzed yearly content release trends using a Line Plot.
Examined the Top 10 Netflix content ratings using a Bar Chart.
Explored movie duration patterns using a Histogram.
